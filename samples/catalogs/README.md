# Sample catalogs

This folder holds only catalogs. It has one folder per catalog version, named by the version, for example `1/`.

It is the one thing the two sample builds share. `samples/app` writes a catalog and `samples/server` reads a copy of it. Neither build uses any code from the other.

See the [quickstart](../../specs/001-consumer-catalog-bridge/quickstart.md) for how a catalog is saved and copied here.
